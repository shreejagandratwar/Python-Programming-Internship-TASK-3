# Expense Tracker 2.0

## Overview

Expense Tracker 2.0 is a Python-based command-line application that helps users manage and analyze their expenses efficiently.

## Features

* Add expenses with categories
* Store records in a CSV file
* View all expenses
* Search expenses by category
* Calculate total spending per category
* Generate monthly spending summaries

## Technologies Used

* Python
* CSV File Handling
* Dictionaries
* Date and Time Module

## Sample Categories

* Food
* Travel
* Shopping
* Bills

## Learning Outcomes

* File Handling in Python
* Data Filtering and Searching
* Expense Data Analysis
* Building Menu-Driven Applications
